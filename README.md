# Sorting Algorithms Visualizer

## 📌 Overview
This project is a **Sorting Algorithms Visualizer** built using frontend technologies.
It visually demonstrates how different sorting algorithms work step by step.

This helps in understanding:
- Comparisons
- Swaps
- Time behavior of sorting algorithms

---

## 🎯 Objective
- To visualize sorting algorithms
- To improve understanding of algorithm flow
- To make learning data structures interactive

---

## 🧠 Algorithms Implemented
- Bubble Sort
- Selection Sort
- Insertion Sort

---

## 🖥️ Features
- User-defined input array
- Random array generation
- Animated sorting process
- Highlighting of comparisons and swaps
- Real-time statistics display

---

## 🛠 Technologies Used
- HTML – Structure
- CSS – Styling and layout
- JavaScript – Logic and animations
